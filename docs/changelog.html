The first version: four crates, one of them the Python package.

silvic-core
LightGBM 3.3.5’s parameters, binning, objectives (regression, binary, lambdarank) and metrics; leaf-wise trees on quantized integer histograms, bit-reproducible on any number of ranks; LightGBM model text, read and written byte for byte; the CPU backend.
silvic-gpu
Metal and CUDA backends from one kernel source, one device wait per split. Metal matches the CPU backend bit for bit on quantized L2; CUDA compiles but has not run on NVIDIA hardware.
silvic-net
TCP ring allreduce and allgather with a token handshake, a fixed fold order, and failures that travel around the ring instead of hanging.
silvic-python
The silvic package with LightGBM’s Python API and scikit-learn estimators, and silvic.ray.train, whose model equals single-process training on the same rows.
