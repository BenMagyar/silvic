silvic, LightGBM-compatible gradient boosting, is four Rust crates, one of which builds the silvic Python package, version 0.1.0 and not yet released (changelog). Build the package from a checkout into a Python 3.10 or newer environment:

maturin develop --release

Then train as with LightGBM, with the same parameter names:

import silvic

params = {"objective": "lambdarank", "num_leaves": 53, "device_type": "auto"}
train_set = silvic.Dataset(X, label=y, group=query_sizes, categorical_feature=[131, 132])
booster = silvic.train(params, train_set, num_boost_round=1500)
scores = booster.predict(X_test)

Rust 1.94.1 or newer builds it. Metal runs on Apple silicon; CUDA needs an NVIDIA driver and NVRTC from CUDA 12, and has not yet run on NVIDIA hardware.

Package and crates

silvic-python
The silvic Python package: LightGBM’s Python API, scikit-learn estimators, and training across Ray actors.
silvic-core
Parameters, binning, objectives, metrics, leaf-wise trees on integer histograms, LightGBM model text, and the CPU backend.
silvic-gpu
The Metal and CUDA backends, from one kernel source compiled at run time.
silvic-net
TCP ring collectives for distributed training.
