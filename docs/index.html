silvic

Docs Changelog

Gradient boosting in Rust that trains the models LightGBM trains, on the CPU, Apple Metal or NVIDIA CUDA, in one process or across Ray actors that resume when a node is lost. It writes LightGBM 3.3.5 model text, so LightGBM, its SHAP values and lleaves serve its models unchanged, and it scores LightGBM’s models itself, in Python or as a Triton backend, several times faster, with LightGBM’s predictions bit for bit. Its histograms are integer sums of quantized gradients: every run gives the same model, and Ray workers train the model one process would.

Against LightGBM

Use it

pip install silvic
pip install "silvic[ray]"
import silvic

train_set = silvic.Dataset(X, label=y, group=query_sizes)
booster = silvic.train({"objective": "lambdarank"}, train_set, num_boost_round=1500)
booster.save_model("model.txt")
import silvic.ray

booster = silvic.ray.train(params, ray.data.read_parquet("s3://bucket/train/"),
                           label_column="label", group_column="query_id",
                           num_workers=5, use_gpu=True)
import silvic.serve

predictor = silvic.serve.Predictor("model.txt")  # any LightGBM 3.x or 4.x model
scores = predictor.predict(candidates, num_threads=1)
